# Project Brief — Folio3 Task Management App

> **BMAD artifact:** Analyst output. Feeds the [PRD](prd.md).
> **Status:** Draft v0.1 — awaiting stakeholder input.

## Problem Statement

Teams at Folio3 (and comparable organizations) coordinate work across scattered tools — chat threads, spreadsheets, email — making it hard to see who is doing what, by when, and what is blocked. A focused, lightweight task management app can centralize this.

## Proposed Solution

A web-based task management application where users organize work into projects, create and assign tasks, track status and deadlines, and get visibility through boards and simple reporting.

## Target Users

- **Team members** — create, update, and complete tasks assigned to them.
- **Team leads / project managers** — organize projects, assign work, monitor progress and deadlines.

## Goals

- Single place to capture, assign, and track tasks.
- Clear visibility of task status and ownership at a glance.
- Low-friction: a new user can create their first task within minutes.

## Out of Scope (initial release)

- Native mobile apps
- Time tracking / billing
- Third-party integrations (Slack, Jira, calendar sync)
