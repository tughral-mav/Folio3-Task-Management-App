# Story 6.3 — Responsive & Accessibility Pass

**Status:** Review (2026-08-11) — automated viewport verification lands with the Epic 7 E2E suite
**PRD:** [Epic 6](../requirements/prd.md#epic-6--dashboards--polish) · NFR1, NFR5, NFR7

Systematic pass over every surface:

- **Navigation:** skip-to-content link (visually hidden until focused); role-based primary nav in the sticky header, horizontally scrollable on narrow screens (no horizontal page scroll); `main` landmark with id.
- **Responsive:** task lists switch table→cards below `md`; stat grid 2→3→6 columns; forms single-column on mobile; filter bar wraps; touch-sized targets (≥36px) throughout.
- **A11y:** labelled form controls everywhere; `aria-live`-equivalent unread announcements via the bell label; status/priority/overdue always symbol+label+color (never color alone); visible focus rings on all interactive elements; `role=alert/status` on form feedback; sr-only "(unread)" markers; semantic landmarks (`header/nav/main/section` with labels).
- **States:** loading skeleton, error boundary, and designed empty states on every list surface.

Remaining for Epic 7: Playwright viewport matrix (360×640 / 390×844) executing the Test 13 checklist + axe scan.
