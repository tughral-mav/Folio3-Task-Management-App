# Story 1.3 — CI Pipeline

**Status:** Done (2026-08-11)
**PRD:** [Epic 1](../requirements/prd.md#epic-1--foundation--infrastructure)

GitHub Actions (`.github/workflows/ci.yml`), two jobs on pushes to `develop` and PRs to `develop`/`main`:
1. **quality** — `npm ci`, lint, typecheck, unit tests, production build (Node 24).
2. **schema** — Supabase CLI on the runner: `supabase db start` applies all migrations + seed to fresh Postgres, then `scripts/verify-schema.sql` asserts tables/RLS/triggers/functions, fan-out counts, completed_at maintenance, and that a non-Folio3 auth insert is **rejected** by the domain gate.

**AC check:** a failing check blocks the merge (GitHub default for failed checks on PRs); red/green verified on the first pushes.
