# Story 7.2 — End-to-End Test Suite

**Status:** Done (2026-08-11) — **28/28 green in CI** (desktop + Pixel 7)
**PRD:** [Epic 7](../requirements/prd.md#epic-7--hardening-verification--deployment) · Tests 6, 7, 9, 10, 12, 13

Playwright suite (`tests/e2e/`) against a local build + full local Supabase stack, using **session injection** (test strategy §2): `global-setup.ts` mints a Supabase session for the seeded admin/member via the GoTrue admin API and captures the exact `@supabase/ssr` auth cookies into Playwright storageState — no live Google in CI. Runs on desktop + Pixel 7 (mobile) projects.

Specs:
- **unauth** — login offers Google only, zero form inputs (FR1); protected routes redirect to `/login` (proxy guard); access-denied renders; no horizontal overflow.
- **admin** — dashboard + stat cards; create & assign a task, verify on detail + in the list (Test 6).
- **member** — sees own tasks, not others' (FR14); submits a progress update, sees it appear (Test 7); opening a notification decrements the unread badge (Test 9).
- **security** — member bounced from `/admin` (Test 12, UI); member opening another user's task id hits the not-found state (Test 10, UI/IDOR).
- **mobile** — every authenticated member surface has no horizontal overflow at mobile viewport (Test 13).

CI job `e2e`: `supabase start` (full stack) → export local keys → `npm run test:e2e`; uploads the Playwright report artifact. iOS Safari (WebKit) spot-check remains manual.
