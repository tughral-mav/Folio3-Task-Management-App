# Epic 8 — Trello-Style Board, Dated Progress & Consistent Template

**Status:** Review (2026-08-12)
**PRD:** [Epic 8](../requirements/prd.md#epic-8--trello-style-board-dated-progress--consistent-template-v03) · FR37–FR41

Stakeholder feedback (v0.3): Trello-like UI, member multi-update progress shown by date to the admin, one consistent page template.

- **8.1 Shared template & board primitives** — `components/ui/page-header.tsx` (`PageHeader`: back/title/subtitle/actions); `components/board/` (`TaskCard`, `Board` read-only, `groupByStatus`, `BOARD_COLUMNS`). Trello aesthetic: gray columns with accent bars + count badges, white cards.
- **8.2 Admin board** (`/admin/board`) — `AdminBoard` client: drag-and-drop between columns **and** a keyboard-accessible per-card status `<select>` (NFR5), optimistic move + revert on failure, via new `moveTaskStatusAction` (admin-only; requireAdmin + admin-only RLS; triggers still record activity + notify). FR37/FR38.
- **8.3 Member board** (`/my/board`) — read-only `Board` of own tasks (RLS-scoped); no status control; open a card → detail. FR39.
- **8.4 Dated progress** — `UpdatesList` groups `task_updates` by calendar date (newest day first) with date headers; members add multiple; admin reads the history by date. `dates.ts` gains `dayKey`/`formatTime`. FR40; updates remain immutable (A3).
- **8.5 Template rollout** — `PageHeader` applied to dashboards, tasks list, new/edit task, team, my tasks, activity, notifications, task detail; Board added to primary nav for both roles. FR41.
- **8.6 Playwright** — `board.spec.ts` (columns render; admin status move persists; member board read-only, no selects) + `dated-progress.spec.ts` (member submits two updates across contexts; admin sees both under a dated group).

Local verification: lint, typecheck, 16/16 unit, production build (adds `/admin/board`, `/my/board`). Security model unchanged — the board adds no client authority; member status still only via the progress-update RPC.
