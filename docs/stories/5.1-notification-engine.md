# Story 5.1 — Notification Engine

**Status:** Review (2026-08-11)
**PRD:** [Epic 5](../requirements/prd.md#epic-5--notifications--realtime) · FR26–FR28, FR33

Write side has been live since Story 1.4 (trigger fan-out, ADR-4/8: recipients `{assignee, creator} − {actor}`, one consolidated notification per save, creator-only progress notifications per D2, `notify_user` as the future preference hook per FR33). This story adds the read side: `listNotifications` / `unreadCount` queries (RLS recipient-scoped, partial-index-backed count) and `openNotificationAction` / `markAllReadAction` (RPC, race-safe per EC-N3).
