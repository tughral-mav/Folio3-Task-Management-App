# Story 3.2 — Edit, Status, Reassign

**Status:** Review (2026-08-11)
**PRD:** [Epic 3](../requirements/prd.md#epic-3--task-management-admin) · FR13

`/admin/tasks/[id]/edit`: full-field edit incl. any status and reassignment (`taskEditSchema`, `updateTaskAction` — requireAdmin + RLS). DB triggers handle the rest (Story 1.4): `completed_at` set/cleared (EC-T4), one consolidated notification per save (EC-N6), reassignment notifies new + courtesy old assignee (EC-T2), recipients `{assignee, creator} − {actor}` (ADR-8).
