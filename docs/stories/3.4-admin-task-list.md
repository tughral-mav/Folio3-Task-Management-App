# Story 3.4 — Admin Task List, Search & Filters

**Status:** Review (2026-08-11)
**PRD:** [Epic 3](../requirements/prd.md#epic-3--task-management-admin) · FR17, FR36

`/admin/tasks`: URL-driven (shareable, server-rendered) combinable filters — search across title/description/assignee-name-or-email, status, priority, assignee, due-date range — plus pagination (25/page) and overdue badges. Responsive per NFR1: real table on desktop, card list on mobile. `/admin/team` lists provisioned members with roles. Admin dashboard links the surfaces (full stats land in Epic 6).
