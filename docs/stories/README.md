# Stories

BMAD development-phase artifacts. Each story from the [PRD's epics](../prd.md#epic-list) is sharded here as its own file when it enters development:

```
docs/stories/<epic>.<story>-<slug>.md   e.g. docs/stories/1.1-project-scaffold.md
```

A story file contains: the story statement, acceptance criteria (copied from the PRD at draft time), dev notes, task checklist, and a status line (`Draft → Approved → In Progress → Review → Done`).
