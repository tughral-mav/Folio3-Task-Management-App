# Story 5.4 — Live Dashboard Updates

**Status:** Review (2026-08-11)
**PRD:** [Epic 5](../requirements/prd.md#epic-5--notifications--realtime) · FR32

One mechanism serves every surface: `RealtimeRefresher` re-renders the server-component tree on the caller's own notification/task events, so member dashboards, task lists, task detail, badge, and notification center all reflect admin changes without manual reload (Test 8 "member sees update"). Admin surfaces refresh on focus/navigation rather than a global task firehose (architecture §7 choice — avoids an unfiltered subscription for all-task visibility).
